================================================================================
ระบบบริหารจัดการชมรมเพื่อนภูผา (Phupha Club Management System)
================================================================================

โปรเจกต์นี้ประกอบด้วย 2 ส่วนหลัก:
1. ระบบเว็บไซต์ (Web Application) พัฒนาด้วย PHP, JavaScript, CSS และ MySQL
2. แอปพลิเคชันมือถือ (Mobile Application) พัฒนาด้วย Flutter (Dart) สำหรับ Android และ iOS

--------------------------------------------------------------------------------
โครงสร้างโฟลเดอร์ของโปรเจกต์
--------------------------------------------------------------------------------
/web_code          - โค้ดระบบเว็บไซต์, ฐานข้อมูล, และ REST API (api.php)
/dart_app          - โค้ดแอปพลิเคชันมือถือ Flutter
/start_tunnel.bat  - สคริปต์เปิดเซิร์ฟเวอร์ออนไลน์ผ่าน Cloudflare Tunnel (ฟรี HTTPS)
/readme.txt        - คู่มือการติดตั้งและใช้งานระบบ

--------------------------------------------------------------------------------
1. วิธีการติดตั้งและรันระบบเว็บไซต์ (Web Application บน XAMPP)
--------------------------------------------------------------------------------
1.1 ดาวน์โหลดและติดตั้งโปรแกรม XAMPP (แนะนำ PHP 8.0 ขึ้นไป)
1.2 คัดลอกโฟลเดอร์โปรเจกต์ไปไว้ที่ htdocs ของ XAMPP เช่น:
    C:\xampp\htdocs\phupha-club
1.3 เปิดโปรแกรม XAMPP Control Panel แล้วกด Start ที่:
    - Apache
    - MySQL
1.4 เข้าสู่ระบบเว็บไซต์ผ่านเบราว์เซอร์:
    http://localhost/phupha-club/web_code
    (ระบบมีคำสั่ง Auto-migration จัดการสร้างและอัปเดตตารางฐานข้อมูลให้อัตโนมัติเมื่อเปิดครั้งแรก)

--------------------------------------------------------------------------------
2. วิธีการเปิดเซิร์ฟเวอร์ออนไลน์ให้คนภายนอกและแอพใช้งาน (Cloudflare Tunnel)
--------------------------------------------------------------------------------
2.1 ตรวจสอบว่าเปิด Apache และ MySQL ใน XAMPP เรียบร้อยแล้ว
2.2 ดับเบิ้ลคลิกเปิดไฟล์:
    start_tunnel.bat
2.3 ระบบจะทำการดาวน์โหลด cloudflared.exe (เฉพาะครั้งแรก) และเปิดอุโมงค์เชื่อมต่อ
2.4 หน้าจอจะแสดงลิงก์ HTTPS ตัวอย่างเช่น:
    https://xxxx-xxxx-xxxx.trycloudflare.com

2.5 การนำลิงก์ไปใช้งาน:
    - สำหรับเข้าเว็บผ่านมือถือ: ให้เข้าลิงก์ตามด้วย /phupha-club/web_code เช่น:
      https://xxxx-xxxx-xxxx.trycloudflare.com/phupha-club/web_code
    - สำหรับแอพมือถือ: นำลิงก์ไปใส่ในไฟล์:
      dart_app/lib/constants/app_config.dart
      ตรงตัวแปร `static String baseUrl = 'https://xxxx.trycloudflare.com/phupha-club/web_code';`

*หมายเหตุ: ต้องเปิดหน้าต่าง start_tunnel.bat ทิ้งไว้ตลอดเวลาที่ต้องการให้ออนไลน์*

--------------------------------------------------------------------------------
3. วิธีการรันและ Build แอปพลิเคชันมือถือ (Flutter Mobile App)
--------------------------------------------------------------------------------
3.1 ติดตั้ง Flutter SDK (เวอร์ชัน 3.x ขึ้นไป) และ Android Studio
3.2 เปิดโฟลเดอร์ dart_app ใน Terminal หรือ Command Prompt
3.3 สั่งดาวน์โหลดแพ็กเกจ:
    flutter pub get
3.4 รันแอพพลิเคชันเพื่อทดสอบ:
    flutter run
3.5 การสร้างไฟล์ติดตั้งสำหรับ Android (.apk):
    flutter build apk --release
    ไฟล์ที่ได้จะอยู่ที่:
    dart_app/build/app/outputs/flutter-apk/app-release.apk
3.6 นำไฟล์ app-release.apk ไปวางไว้ที่:
    web_code/uploads/app-release.apk
    เพื่อให้สมาชิกกดดาวน์โหลดผ่านหน้าเว็บในมือถือได้โดยตรง
