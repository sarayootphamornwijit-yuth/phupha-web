# Phupha Club Web Application (ชมรมเพื่อนภูผา)

ระบบเว็บไซต์และระบบบริหารจัดการข้อมูล (ERP) สำหรับชมรมเพื่อนภูผา มหาวิทยาลัยราชภัฏเชียงใหม่

## ฟังก์ชันการทำงานหลัก
- **ระบบสมาชิกและการเข้าสู่ระบบ:** รองรับทั้งสมาชิกทั่วไป นักศึกษา กรรมการ และที่ปรึกษา
- **ระบบกิจกรรม:** แสดงรายการกิจกรรมใหม่ ข่าวสาร และประวัติกิจกรรมที่ผ่านมา
- **ระบบประเมินผลและเกียรติบัตร:** จัดการเกณฑ์คะแนนและออกเกียรติบัตรออนไลน์
- **ระบบ ERP บริหารชมรม:** จัดการงบประมาณ ยานพาหนะ และรายงานต่างๆ
- **RESTful API (`api.php`):** ให้บริการข้อมูลสำหรับแอปพลิเคชัน Mobile (Flutter)
